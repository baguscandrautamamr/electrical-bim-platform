# Roadmap

## Phase 1 — MVP (current)

- Revit 2025 ribbon and connector.
- Electrical element metadata sync.
- Dashboard, BIM Chat baseline, and remote job queue.
- Safe Revit execution through `ExternalEvent`.

## Phase 2 — Production foundation

- PostgreSQL/Supabase schema with project tenancy.
- JWT/OIDC authentication and device registration.
- Durable queue, retries, heartbeat, idempotency, and audit log.
- Incremental sync for added, modified, and deleted elements.
- Installer/MSI and signed add-in binaries.

## Phase 3 — Electrical intelligence

- Panel/circuit load analytics and imbalance detection.
- Cable sizing, voltage-drop, tray fill, grounding, and BOM modules.
- Retrieval-based BIM Chat with citations to element parameters.
- Web-to-Revit selection and parameter approval workflow.

## Phase 4 — Delivery

- PDF/IFC/DWG background exports.
- 3D web viewer with glTF geometry pipeline.
- Multi-project portfolio dashboard and notifications.
