ELECTRICAL BIM PLATFORM - REVIT 2025

1. Extract ZIP ini ke sebuah folder.
2. Tutup Autodesk Revit 2025.
3. Klik kanan Install-ElectricalBim.ps1 lalu Run with PowerShell.
   Alternatif dari PowerShell:
   powershell -ExecutionPolicy Bypass -File .\Install-ElectricalBim.ps1
4. Jalankan backend Electrical BIM Platform pada komputer/server yang dapat diakses.
5. Buka Revit 2025, lalu klik Electrical BIM > Connect.

Versi MVP ini memakai URL backend http://localhost:5080 dan project demo.
Untuk memakai server kantor, URL perlu diubah pada konfigurasi add-in versi berikutnya.
